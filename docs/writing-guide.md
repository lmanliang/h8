# 文件撰寫規範

本文件定義專案文件的撰寫標準，確保所有文件風格一致。

---

## 語言與格式

| 項目 | 規範 |
|-----|------|
| 語言 | 繁體中文 |
| 檔案格式 | Markdown (.md) |
| 編碼 | UTF-8 |
| 命名規則 | `topic/topic.md` (與目錄同名) |

---

## 標題層級

```markdown
# 文件標題（每個檔案只有一個）

## 主要章節

### 次要章節

#### 細項（盡量避免超過 4 層）
```

---

## 流程圖

**一律使用 Mermaid 語法**，不使用圖片檔案。

### 支援的圖表類型

| 類型 | 用途 | 語法 |
|-----|------|------|
| flowchart | 流程圖、架構圖 | `flowchart TB` / `flowchart LR` |
| sequenceDiagram | 時序圖、互動流程 | `sequenceDiagram` |
| classDiagram | 類別關係圖 | `classDiagram` |
| erDiagram | 資料庫關聯圖 | `erDiagram` |
| stateDiagram | 狀態機 | `stateDiagram-v2` |

### 範例

````markdown
```mermaid
flowchart LR
    A[開始] --> B[處理]
    B --> C[結束]
```
````

### 為什麼用 Mermaid？

| 優點 | 說明 |
|-----|------|
| 版本控制 | 純文字，可追蹤變更 |
| 易於維護 | 修改文字即可，不需重繪圖片 |
| 一致性 | 自動排版，風格統一 |
| 可搜尋 | 圖表內容可被搜尋 |

## 表格

用於對比、列舉、規格說明：

```markdown
| 欄位 A | 欄位 B | 欄位 C |
|-------|-------|-------|
| 值 1  | 值 2  | 值 3  |
```

## 程式碼區塊

### 標註語言類型

````markdown
```ruby
def hello
  puts "Hello, World!"
end
```
````

### 常用語言標籤

| 標籤 | 用途 |
|-----|------|
| `ruby` | Ruby 程式碼 |
| `yaml` | 設定檔 |
| `sql` | SQL 語法 |
| `bash` / `shell` | 終端指令 |
| `json` | JSON 資料 |
| `markdown` | Markdown 範例 |

### 程式碼範例原則

- 提供**可執行**的完整範例
- 加上**註解**說明重點
- 避免過長，必要時拆分說明

---

## 文件結構

每份文件建議包含：

```markdown
# 文件標題

簡短說明這份文件的目的。

---

## 概述（選填）

背景、動機、整體說明。

---

## 主要內容

（依主題分章節）

---

## 總結（選填）

重點摘要。
```

## 檔案命名

| 規範 | 範例 |
|-----|------|
| 使用小寫英文 | `spec.md`, `data.md` |
| 單字間用 `-` 連接 | `writing-guide.md` |
| 避免空格和特殊字元 | ❌ `Writing Guide.md` |
